# suno_prompt_studio_v5
A simple tool for creating style prompts for Suno AI. It allows you to select musical instruments, styles, time signatures, and moods—among many other options—using a slider to adjust the song's tempo, all with just a few clicks. We are currently on version 5, and we plan to include even better features in future updates. I hope you find it enjoyable, helpful, and a great time-saver. The generated prompts can be edited directly within the interface, and once finished, you can either export the prompt to a text file or copy it to paste directly into Suno AI.
